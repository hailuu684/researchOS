# Research Standard Framework

This repository provides a research-standard framework tailored for university students and independent researchers aiming to achieve high-quality, publication-ready results.

---

## 🚀 Getting Started

### 1. Configure Environment Variables
* Copy the `.env.example` file and rename it to `.env`.
* Open `.env` and insert your private API keys.
* **Important:** Ensure you are running the application using the actual `.env` file, not the example template.

### 2. Run the Application
Choose one of the following execution methods depending on your needs:

* **Persistent Web Interface (Up to 1 Week):**
  ```bash
  gradio test_app.py
  ```
* **Single-Session/One-Time Run:**
  ```bash
  python test_app.py
  ```
